# Project Journey Hub

Crie um site moderno, elegante e intuitivo para apresentação e acompanhamento das etapas do projeto para a Feira de Projetos, baseado nos requisitos das fotos anexadas:

1. Estrutura geral e navegação:
- Cabeçalho com identidade do projeto (Nome Fantasia e Nome do Grupo) e barra de progresso / timeline das etapas (Etapa 01 em destaque e abas/seções modulares fáceis de preencher para as próximas etapas).
- Design profissional, limpo, responsivo e com visual tech/maker de alto nível (tipografia moderna, cards bem desenhados, modo claro/escuro opcional ou visual clean refinado).

2. Conteúdo da Etapa 01 (totalmente estruturado e com dados de exemplo editáveis):
- Nome do Grupo (conforme sala virtual) e Nome Fantasia da equipe/projeto.
- Seção da Equipe com cards dos integrantes (com foto/avatar placeholder customizável, nome, função no projeto e contato/bio).
- Proposta do Projeto: apresentação da aplicação prática voltada para o dia a dia (Indústria, Residência ou Comércio), contexto do problema e justificativa.
- Arquitetura Técnica do Sistema (com diagramas ou visual cards interativos):
  * Sinais de Entrada (Sensores, botões e sinais de acionamento)
  * Processamento (CPU / Microcontrolador: Arduino, ESP32, Raspberry Pi)
  * Sinais de Saída (Drivers, atuadores, motores, relés, displays)

3. Usabilidade:
- Interface organizada para que os alunos possam facilmente atualizar nomes, fotos, textos da proposta e adicionar as documentações das etapas seguintes.
